# TG-008: синтетический каталог демо

После migrations запустите из корня репозитория с `DATABASE_URL`:

```powershell
node packages/db/src/seed/cli.ts
```

Используйте закреплённые Node 24.21.0 и npm 11.19.0. Команда добавляет отсутствующие записи каталога и сохраняет существующие настройки, время создания, DemoRun и Case. Ключи и UUID версии `tg008.v1` находятся в `index.ts`; смена этих значений требует отдельной миграции fixture contract. Seed не создаёт MAX identity, DemoRun или Case. Каталог содержит только вымышленные данные.

Пять записей `DEMO_ACTOR_ALLOWLIST` служат шаблоном для владельца TG-013. Для каждого нового DemoRun именно TG-013 создаёт `DemoRunActor` и новый Case через продуктовые команды. Сам seed не запускает демо повторно.
