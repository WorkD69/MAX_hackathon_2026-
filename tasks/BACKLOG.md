# Этапы CREATE

Разработка приложения не начата. Этот план фиксирует только крупные этапы; конкретные задачи появятся после утверждения технических интерфейсов. Текущий gate: [PROJECT_STATE](../docs/08_PROJECT_STATE.md).

| Приоритет | Этап | Результат |
| --- | --- | --- |
| P0 | Technical Architecture | Проект архитектуры для рассмотрения командой. |
| P0 | Data Model / Contracts | Согласованные модель данных и технические контракты. |
| P0 | Technical Architecture Review | Явное утверждение или перечень замечаний. |
| P0 | Task Graph | Зависимости и границы будущих задач. |
