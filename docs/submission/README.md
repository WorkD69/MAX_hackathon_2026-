# Материалы финальной сдачи

Сюда нужно положить финальную PDF-презентацию перед сдачей и указать её имя в корневом README.
Локально найдены только черновые PDF с `[FINAL_*]` placeholders; ни один не подтверждён как финальный.
Первый слайд должен содержать работающие Bot/Mini App/API URL, репозиторий, полный submission SHA
и маршрут экспертной проверки. Проверить отсутствие токенов, initData, chat ID и реальных credentials.

Проверки пакета: [checklist](SUBMISSION_CHECKLIST.md), [runbook](VERIFICATION.md),
[известные ограничения](KNOWN_LIMITATIONS.md), [SYNTHETIC данные](SYNTHETIC_DATA.md).
